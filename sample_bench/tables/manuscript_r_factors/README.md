# Combined manuscript R-factor tables

Generated by sample_bench/notebooks/exp/manuscript_r_factors.ipynb.

R-work is from the model selected by minimum R-free for that dataset. † Refinement status unverified: the supplied summary is named vipul_1s2c_phenix_ref, but its model paths omit _phenix_ref. Values are included as supplied. — indicates no configured summary for that stage. * on 298 K is retained from the manuscript. The PDB reference values use distinct withheld reflections (manuscript caption).

The before_phenix files correspond to manuscript Tables 3–4; phenix_summary files extend Tables 5–6 with Vipul's 1-state/2-condition and 2-state/4-condition results. No separate pre-Phenix summaries are configured for Vipul.

Table CSVs display three decimals. selected_models.csv retains full precision and records source CSV, physical row (zero-based), CSV line (one-based, including header), original index label, contributor, condition combination, and model path. source_manifest.csv records input hashes; coverage.csv counts summary candidates, not independent trajectories. manuscript_comparison.csv is written when the source manuscript is available.
